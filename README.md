# LeetCode

Soluções do meu roteiro de estudos para entrevistas técnicas: 14 módulos e 117 problemas, do básico ao avançado.

## Como funciona

- Cada problema tem uma **issue** (`[MM.NN] Nome`), na ordem do roteiro.
- Cada módulo é um **milestone** — a barra de progresso dele mostra quanto já foi resolvido: [ver milestones](https://github.com/arthurneto2/LeetCode/milestones?direction=asc&sort=title&state=open).
- Labels: `nível 1 - básico`, `nível 2 - intermediário`, `nível 3 - avançado` e `fácil` / `médio` / `difícil`.
- A solução vai na pasta do módulo, com o nome `NN-slug-do-problema.<extensão>` (ex.: `01-arrays-hashing/01-two-sum.py`).
- Feche a issue pelo commit: `git commit -m "01.01 Two Sum (closes #1)"`.

Próximo problema em aberto: [issues abertas em ordem](https://github.com/arthurneto2/LeetCode/issues?q=is%3Aissue+is%3Aopen+sort%3Acreated-asc).
